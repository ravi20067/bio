# Bio

**Bio** is a clean, lightweight frontend project showcasing personal information through separate user and admin interfaces. Crafted to deliver a simple and intuitive experience, it features static pages organized by function and role.

---

##  Project Structure

assets/ → Contains images, CSS styles, JavaScript, and other static resources
data/ → Holds data files (e.g., JSON), if any
pages/ → Contains individual HTML pages (specific role-related pages)
index.html → Main entry point or landing page


---


---

##  Tech Stack

- **HTML5** – Content structure and layout  
- **CSS3** – Styling and responsive design  
- **JavaScript** – Basic interactivity and dynamic behavior  
- **Static Data** – Optionally integrated via files in the `data/` folder  

---

##  Summary

**Bio** is a front-end oriented, role-aware web project that demonstrates separation of concerns via user and admin navigation. It's structured for clarity, using organized directories for assets, data, and role-based page segregation.
